# Metro Manila Number Coding Checker

A responsive, WordPress-ready JavaScript coding hour checker inspired by common Metro Manila UVVRP workflows.

## WordPress installation

1. Open **Pages → Add New** or use an Elementor/Custom HTML block.
2. Paste the markup and `<style>/<script>` blocks from `index.html` into the page.
3. Do not include the outer `<!doctype html>`, `<html>`, or `<head>` tags in an existing WordPress page.

For a theme template, copy the `.checker` markup and CSS/JavaScript into a custom shortcode or template.

## Features

- Plate last-digit validation
- Monday–Friday UVVRP schedule
- Weekend and holiday/suspension handling
- Standard window-hour guidance
- Makati continuous coding option
- Route-specific Marikina and Muntinlupa handling
- 7-day coding overview
- Copy and native share actions
- Responsive mobile layout
- Travel-date and travel-time validation

## Important

Coding suspensions, emergency declarations, exemptions, and LGU road-specific rules can change. Confirm these with MMDA or the relevant LGU before travel. This tool is a guide, not an official enforcement source.
